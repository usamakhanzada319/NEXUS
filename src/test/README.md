# Testing Guide

## Test Stack

| Tool                            | Purpose           |
| ------------------------------- | ----------------- |
| **Vitest**                      | Test runner       |
| **React Testing Library**       | Component testing |
| **Jest DOM**                    | DOM matchers      |
| **@testing-library/user-event** | User interactions |

## Running Tests

```bash
# Watch mode
npm test

# Run once
npm run test:run

# Coverage
npm run test:coverage

# UI mode
npm run test:ui
```
